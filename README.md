# Emobot

**Emobot** is a personalized LLM-based assistant that detects user emotion from conversations and can take actions using external tools such as Google Calendar and Gmail via API integrations. It aims to make AI agents not only smarter, but more empathetic and context-aware.

---

## Features

- **Emotion-Aware Chat**  
  Detect user emotions in real-time from text, enabling more natural and empathetic responses.

- **Tool Calling Support**  
  Capable of calling external APIs via structured function calls (e.g., `get_weather`, `create_event`).

- **Google API Integration**  
  Support for Google Calendar or Gmail, with OAuth2-based authentication and context-aware actions.

- **User Personalization**  
  Memory and context tracking to support long-term personalization, including tone/style preferences.

- **LLM-Powered Reasoning**  
  Powered by models like Gemini 2.5 Pro, GPT-4, or LLaMA-3 (local), with custom tool-using agents.
